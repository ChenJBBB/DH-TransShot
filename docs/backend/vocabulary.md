# 生词本

`vocabulary.rs` 为独立文件存储模块，`commands/vocabulary.rs` 提供三个 RPC：
`save_vocabulary`、`get_vocabulary_directory`、`open_vocabulary_directory`。
不调用翻译、OCR 或 TTS API。

目录使用 Tauri 的系统文档路径（兼容 Windows 文档重定向），其下为 `DH-TransShot/生词本`。
文件命名 `生词本_0001.txt`、`生词本_0002.txt`……，UTF-8、LF 换行。
设置 → 生词本 显示完整路径，并通过系统文件管理器打开该目录；不会执行用户提供的命令或路径。

每个文件最多 2000 个 Unicode 字符（`chars().count()`，含标点、空格和换行，非字节数）。
每条记录保留完整选词（最多 1000 字）、上下文（最多 500 字）、对应原文/译文节选（最多 300 字）、
选取位置和本机收藏时间。节选超限追加省略号。记录整体超过当前文件剩余额度时，写入下一个编号文件，
不拆开记录。扫描已有编号文件后续写，重启不清零；同词、同上下文的重复收藏返回已有文件。

磁盘工作在 `spawn_blocking` 上执行。`.vocabulary.lock` 使用系统文件锁，串行化线程及多个应用实例的写入；
关闭文件句柄（包括进程崩溃）自动释放锁。写入后 `sync_data`，读取/写入错误原样反馈，
不覆盖已有记录。应用卸载不删除文档中的生词本。

测试覆盖中日文与 emoji 计数、2000 字恰好装满、跨文件轮转、完整记录、长上下文截取、
重复收藏、重启续写与并发写入。
